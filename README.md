# Owen

A minimal personal and academic website, built with HTML, CSS, and JavaScript. No dependencies or build step.

- `index.html`: introduction and resource links
- `portfolio.html`: academic work
- `learning.html`: interactive quadratic graph
- `about.html`: short introduction

Run locally with `python3 -m http.server 8000 --bind 127.0.0.1` from this directory. GitHub Pages serves the files directly.

Add real academic work to the home and work pages. Update the introduction in `about.html` as needed. No academic affiliations, qualifications, or personal contact details are assumed.

`theme.js` remembers the selected theme and provides the splatter reveal in browsers supporting View Transitions, with instant switching for reduced motion or unsupported browsers.
